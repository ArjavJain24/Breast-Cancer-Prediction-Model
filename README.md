# Breast-Cancer-Prediction-Model
This project focuses on developing a machine learning model to predict whether a breast tumor is malignant or benign using the Breast Cancer Wisconsin dataset. The process involves key steps such as data preprocessing, exploratory data analysis (EDA), feature selection, and model training and evaluation.

The workflow includes:
oading and exploring the dataset to understand the distribution and correlation of features.
Data cleaning and scaling using StandardScaler to normalize input features.
Splitting the data into training and test sets for unbiased evaluation.
Training multiple classification models including:
Logistic Regression
K-Nearest Neighbors (KNN)
Support Vector Machine (SVM)
Decision Tree
Random Forest
Evaluating model performance using accuracy, confusion matrix, and classification report metrics.
The final model achieves high accuracy, demonstrating the effectiveness of machine learning in early detection of breast cancer, which is crucial for timely diagnosis and treatment.
